# Robo-Scoop 3000

A classroom simulator for teaching the basics of programming. Students write plain-English instructions, one per line, and a very literal robot tries to make an ice cream cone. It does exactly what they say, nothing more.

**Live page:** https://mr-menno.github.io/robo-scoop/

## Levels

1. **One scoop:** soft ice cream. Practices sequence and precision.
2. **Two scoops:** rock-hard ice cream that needs a warm scoop every time. Practices loops (`repeat 2 times … end`).
3. **Three scoops:** unpredictable ice cream. Practices decisions (`if ice cream is hard … end`).

## Using it in class

- Project the page and have the class call out steps while you type.
- Use **Step** to run one line at a time and ask students to predict what happens next.
- The robot manual on the page lists every word the robot understands.
- Sample solutions are in the collapsed teacher panel. Keep it closed while projecting.

## Running locally

It's a single self-contained `index.html`. Open it in any modern browser; no build step or server needed.
